# Vibe 语音输入 —— 领域术语表

Vibe coding 语音输入：对着 AI Passport 说话，识别出的文字落到 Mac 上当前聚焦的编码工具里。

## 术语

**设备（Device）**：
用户佩戴的 AI Passport。负责采音、显示状态与实时文字、发送按键意图；自身不做识别。
_避免_：板子、硬件、客户端

**配套程序（Companion）**：
与设备配对的 macOS 应用，负责语音识别，并对**目标**执行操作。
_避免_：主机、服务端、守护进程、助手

**目标（Target）**：
片段的去处，在设备上选择并一直保持到更换。分为**App 目标**和**Orca 会话**。
_避免_：目标、目的地

**App 目标（App Target）**：
一个 Mac 应用（或"跟随焦点"），插入前先被激活，再向其当前输入处粘贴。其当前会话即应用中已打开的那个，无法从外部挑选。

**Orca 会话（Orca Session）**：
一个正在运行的 Orca 托管终端。文字直接投递进去，不依赖焦点和粘贴。

**目标标题（Target Title）**：
设备上显示的目标当前会话名称（例如微信聊天对象），让用户在提交前看清文字会落到哪里。

**听写（Dictation）**：
从按下 OK 到再次按下 OK 的一次录音。进行中时音频流式发往配套程序，设备上显示**临时文字**。
_避免_：会话、录音、语句

**临时文字（Partial Text）**：
听写过程中的临时识别结果，可能还会变化，永远不会被插入。

**片段（Segment）**：
一次结束的听写得到的最终文字，以一次粘贴插入目标。只记住最近一个片段。
_避免_：块、短语

**插入（Insert）**：
把片段放到目标光标处，不按回车。

**提交（Submit）**：
在目标按回车（DOWN 键），在编码 Agent 中即发送 prompt。
_避免_：发送、确认

**撤销（Undo）**：
从目标删除最近一个片段（UP 键），仅一次。听写进行中同一按键表示**取消**。

**取消（Cancel）**：
结束听写且不插入任何内容。

## 关系

- 一个**设备**只与一个**配套程序**配对。
- 一次**听写**产生零或一个**片段**（取消或无声时为零）。
- **撤销**只作用于最近一个**片段**，且只能一次。
- **插入**从不提交；只有 DOWN 键提交。
- 目标应用未运行时只提示，绝不自动启动。

## 示例对话

> **开发者：** "如果我手动打了几个字后再**撤销**，会删掉什么？"
> **领域专家：** "配套程序按上一个**片段**的字数删除，所以**插入**后手动编辑会让**撤销**不准，这是可接受的。"

## 已澄清的歧义

- "提交"曾同时指插入文字和按回车。结论：**插入**放置文字，**提交**按回车。
